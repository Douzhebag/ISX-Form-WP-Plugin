สร้างฟอร์มธุรกิจ ส่งอีเมลแจ้งเตือน และจัดการรายการข้อมูลใน WordPress

== Description ==

InsightX Form คือระบบฟอร์มสำหรับธุรกิจ สร้างฟอร์มรับข้อมูลลูกค้า ส่งอีเมลแจ้งเตือนอัตโนมัติ และจัดการรายการที่ส่งเข้ามาได้ครบในหลังบ้าน WordPress

= สร้างฟอร์ม =

* เพิ่มฟิลด์ได้หลายประเภท ได้แก่ ข้อความ ข้อความยาว อีเมล เบอร์โทร ตัวเลข วันที่ และตัวเลือก (radio / checkbox / dropdown)
* กำหนดช่องที่บังคับกรอก พร้อมแจ้ง error ใต้ช่องที่กรอกผิด
* ตั้งสี ความโค้ง และขนาดตัวอักษรของปุ่มส่งแยกแต่ละฟอร์ม
* แสดงฟอร์มบนหน้าเว็บด้วย shortcode `[isxf_form id="123"]` (เปลี่ยน 123 เป็น ID ของฟอร์ม)
* ใช้งานกับ screen reader และคีย์บอร์ดได้

= ส่งอีเมล =

* ส่งผ่าน SMTP ได้ทั้ง Username / Password (มี preset สำหรับ Resend) หรือ OAuth2 ของ Google แบบไม่ต้องเก็บรหัสผ่าน
* ส่งอีเมลตอบกลับลูกค้าและแจ้งเตือนผู้ดูแลอัตโนมัติ
* เลือก template สำเร็จรูป (booking / inquiry) หรือเขียนเองด้วย merge tag เช่น `{site_name}`, `{all_fields}`, `{field:ชื่อ}`
* ดูตัวอย่างอีเมลและส่งอีเมลทดสอบหาตัวเองได้ก่อนใช้งานจริง

= จัดการข้อมูล =

* ดูรายการที่ส่งเข้ามา เปลี่ยนสถานะ เขียนโน้ต กรอง และค้นหา
* ส่งออกเป็นไฟล์ CSV
* หน้า Analytics แสดงจำนวนการส่งรายวัน สัดส่วนสถานะ และฟอร์มยอดนิยม เลือกช่วงวันที่ได้
* Widget สรุปข้อมูลในหน้า Dashboard

= ความปลอดภัย =

* กันสแปมด้วย reCAPTCHA v3 หรือ Cloudflare Turnstile และจำกัดจำนวนการส่งต่อ IP
* รหัสผ่าน SMTP และ OAuth secret ถูกเข้ารหัส (AES-256 + HMAC) ก่อนบันทึก

คู่มือฉบับเต็มอยู่ในเมนู InsightX Form → 📖 คู่มือการใช้งาน ในหลังบ้าน และใน README.md ที่มากับปลั๊กอิน

== Installation ==

= ติดตั้งครั้งแรก =

1. ดาวน์โหลดไฟล์ `insightx-form-<เวอร์ชัน>.zip` จากหัวข้อ Assets ของ GitHub Releases: https://github.com/Douzhebag/ISX-Form-WP-Plugin/releases (ใช้ไฟล์นี้ ไม่ใช่ "Source code")
2. ในหลังบ้าน WordPress ไปที่ ปลั๊กอิน → เพิ่มปลั๊กอินใหม่ → อัปโหลดปลั๊กอิน เลือกไฟล์ ZIP แล้วกด ติดตั้งเดี๋ยวนี้
3. กด เปิดใช้งาน ที่ InsightX Form
4. ไปที่ InsightX Form → ⚙️ ตั้งค่าระบบ เปิด SMTP แล้วกรอกข้อมูลอีเมล (เลือก Google OAuth2, Resend หรือกำหนดเอง) จากนั้นกดปุ่ม ทดสอบส่งอีเมล
5. ตั้งค่า CAPTCHA (reCAPTCHA v3 หรือ Cloudflare Turnstile) ในหน้าเดียวกัน — ถ้าเลือกไว้แต่ไม่ใส่ secret key ระบบจะบล็อกการส่งฟอร์มทั้งหมด
6. ไปที่ InsightX Form → เพิ่มใหม่ สร้างฟอร์มและเพิ่มฟิลด์ แล้วกด เผยแพร่
7. คัดลอก shortcode เช่น `[isxf_form id="123"]` ไปวางในหน้าเว็บ แล้วลองส่งฟอร์มจริงหนึ่งครั้ง

= อัปโหลดโฟลเดอร์เอง =

แตกไฟล์ ZIP แล้วอัปโหลดโฟลเดอร์ `insightx-form` ไปไว้ที่ `wp-content/plugins/` ไฟล์หลักต้องอยู่ที่ `wp-content/plugins/insightx-form/advanced-secure-form.php` ไม่ต้องรัน Composer เพราะในแพ็กเกจมีไฟล์ที่ต้องใช้ครบแล้ว

= เปลี่ยนจากโฟลเดอร์ชื่อเดิม (ISX-Form-WP-Plugin) =

1. สำรองเว็บไซต์ก่อน
2. ปิดใช้งานปลั๊กอินชั่วคราว (ห้ามกด ลบ เพราะจะลบฟอร์ม รายการข้อมูล และการตั้งค่าทั้งหมด)
3. เปลี่ยนชื่อโฟลเดอร์เป็น `insightx-form`
4. เปิดใช้งานอีกครั้ง ข้อมูลเดิมยังอยู่ครบ — อย่าเปิดใช้งานสองโฟลเดอร์พร้อมกัน

== Frequently Asked Questions ==

= ต้องติดตั้ง Composer บนเว็บจริงหรือไม่? =

ไม่ต้อง แพ็กเกจ ZIP จาก GitHub Releases มีไฟล์ runtime ครบแล้ว

= อัปเดตปลั๊กอินอย่างไร? =

ตัวตรวจอัปเดตจะตรวจ GitHub Releases เมื่อมีเวอร์ชันใหม่จะแสดงแจ้งเตือนในหน้า Plugins ให้กด Update now
